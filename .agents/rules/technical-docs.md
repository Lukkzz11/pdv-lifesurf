# Regra Obrigatória: Atualização Contínua da Documentação Técnica

Sempre que você implementar uma nova funcionalidade, tela, serviço, componente, integração ou realizar qualquer refatoração estrutural neste projeto:

1. **Atualize Imediatamente a Documentação:** Você DEVE editar o arquivo `DOCUMENTACAO_TECNICA.md` localizado na raiz do projeto (`c:\PDV - LifeSurf\pdv-lifesurf\DOCUMENTACAO_TECNICA.md`).
2. **Campos a Atualizar:**
   - Adicione a nova funcionalidade na seção correspondente (ou crie uma nova seção se for um módulo inédito).
   - Registre novas rotas na tabela de rotas (`Mapeamento de Módulos e Rotas`).
   - Registre novos arquivos criados na árvore da `Estrutura de Diretórios do Código Fonte`.
   - Atualize a versão e a data no cabeçalho do documento (`Última Atualização`).
3. **Fidelidade com a Base de Código:** Garanta que a documentação técnica reflita exatamente o estado funcional, arquitetural e tecnológico do sistema no momento da entrega.
